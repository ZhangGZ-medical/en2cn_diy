# en2cn_diy

英文 DOCX → 中文 DOCX 格式保留翻译工具。

## 功能

将英文Word文档翻译为中文，**完整保留原文档所有排版格式**（字体、表格、三线表、加粗、斜体、对齐等）。采用"克隆源文件XML结构 + 逐run替换文字"技术，实现零格式损失翻译。

## 触发词

翻译、translate、英译中、en2cn、DOCX翻译、英文文档翻译、保留格式翻译

## 文件结构

```
en2cn_diy/
├── SKILL.md          # 技能定义与SOP（4阶段工作流）
├── en2cn_docx.py     # 通用翻译脚本模板
└── README.md         # 本说明文件
```

## 关键技术

- 源文件克隆 + 逐run文字替换
- 合并单元格/_tc循环引用处理
- 发表级格式零损失，可直接投稿
- 依赖：python-docx

## 成功案例

- 4+4分期框架三线表翻译（5列×8行）
- 多表格文档翻译（含_tc循环引用表格）
- 36行×7列大表翻译（纵向分期行结构）
